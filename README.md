# Flame

A flame animation for the BBC Micro/Master range.

## Credits

All this was inspired by and very very heavily based on PCRetroTech's Youtube video ["A New Fire Effect for the Original IBM PC"](https://www.youtube.com/watch?v=ymrOZHyUrdY).

The random number generator used is [Arlet Ottens' minimal 6502 generator](https://github.com/Arlet/pseudo-random-number-generator/blob/main/6502/minimal-6502.asm).
